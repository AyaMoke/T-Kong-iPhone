# T-Kong for iPhone

**非公式**の Userscript です（**iPhone の Safari 向け**。
[日経電子版](https://www.nikkei.com/)の記事手がかりを端末内に**一時記録**し、[楽天証券版 日経テレコン](https://www.rakuten-sec.co.jp/)での同一記事探しを補助します。

> 日経・楽天証券の公式プロダクトではありません。
> すでに楽天証券版日経テレコンを **正規利用できる方** 向けの操作補助です。

## プラットフォーム

| 環境 | 推奨 |
| --- | --- |
| **iPhone（Safari）** | **T-Kong for iPhone** — `userscript/t-kong.user.js` + [Userscripts](https://apps.apple.com/app/userscripts/id1463298887) |
| **Android** | [T-Kong（Firefox 拡張 / AMO）](https://addons.mozilla.org/ja/android/addon/t-kong/) |

iPad でも同じスクリプトで動作確認済みです（詳細は [導入ページ](./docs/index.html) の「iPad で使う場合」）。
