T-Kong

for iPhone

電子版の記事から、
テレコンへつなぐ。

T-Kong for iPhone — iPhone（Safari）向けの非公式 Userscript です。記事タイトルなどを端末内に一時記録し、楽天証券版日経テレコンでの同一記事探しを補助します。Android の Firefox 拡張版とは別物です。

iPhone に入れる Android の方へ

3ステップ

導入手順

本線は t-kong.user.js（iPhone の Safari）です。Android では別配布の Firefox 拡張を使ってください。

T-Kong for iPhone（Safari + Userscripts）

App Store の Userscripts を使います。日経→テレコンの引き継ぎにはマネージャの GM ストレージが必要です。楽天証券アプリは iSPEED を用意してください。

A. いちばん簡単（URLから入れる）

  1. Safari で次のリンクを開く（パスが .user.js で終わること）:
    raw.githubusercontent.com/.../t-kong.user.js
  2. アドレスバー横の 拡張機能 → Userscripts を開く
  3. インストール確認が出たら追加する
  4. 設定 → アプリ → Safari → 拡張機能 → Userscripts をオンにし、必要なサイトへのアクセスを許可する
  5. 日経の記事ページ（nikkei.com/article/...）を開き、「テレコンで読む」が出るか確認

インストール用URL（Safari で開く）: raw.githubusercontent.com/.../userscript/t-kong.user.js

B. Google Drive などからファイルで入れる

  1. Userscripts アプリを一度開き、保存フォルダを確認する（「このiPhone内」推奨）
  2. t-kong.user.js を Drive 等から端末へ渡す
  3. ファイルアプリで、Userscripts のフォルダ（またはアプリで指定したフォルダ）へコピーする
  4. Userscripts アプリを開き直す → Safari の Userscripts 一覧でスクリプトを ON
  5. 日経記事でボタン表示を確認

Drive の保存先に「Userscripts」が出ないときは、このiPhone内に自作フォルダを作り、Userscripts アプリ側でそのフォルダを保存場所に指定してください。Drive / iCloud 直下を保存場所にすると不安定になりがちです。

iPad で使う場合

手順は iPhone と同じです。実機確認は iPad でも行っており、一連の補助まで動くことを確認しています。楽天証券アプリは iSPEED for iPad （iPhone 用とは別）を使ってください。ファイル保存先の表記は「このiPad内」になります。

Android — Firefox 拡張を推奨

Android では Userscript より、配布済みの Firefox for Android 拡張（AMO）の方が向いています。インストールも更新も楽です。

  1. 端末に Firefox を入れる（目安: 142 以降）
  2. スマホの Firefox で T-Kong（AMO） を開き、Firefox へ追加
  3. 日経記事で「テレコンで読む」が出るか確認

既定ブラウザを Firefox にしておくと、Discover などからも記事が Firefox 側に渡りやすくなります。

使い方

  1. nikkei.com トップで「きょうの新聞」→ iSPEED → テレコン経由できょうの新聞
  2. nikkei.com の記事で「テレコンで読む」→ タイトルなどを一時記録
  3. iSPEED が開いたら、メニュー → マーケット → 日経テレコン
  4. 許諾画面（自動同意は既定 ON。オフ可）
  5. テレコン側で検索〜本文オープンを補助（手動ボタンは「記録した記事を開く」）

Userscripts のメニューから T-Kong for iPhone: 設定、きょうの新聞 も使えます。

うまくいかないとき

一覧でスクリプトが灰色
タップして ON にする。日経の記事URLを開いた状態で一覧を見直す。ファイル名が .user.js か、中身の先頭が ==UserScript== か確認。
ボタンは出るが、テレコン側で記録が消える
GM ストレージ未対応のマネージャ／権限不足の可能性。Userscripts や Violentmonkey で GM.setValue 系が使える状態か確認。
アプリ起動のあとストアの「入手不可能」へ飛ぶ
古いスクリプトの自動フォールバックが原因のことがあります。最新の t-kong.user.js（0.5.1以降）に差し替えてください。
「この操作を継続できません」と出る
セッション切れです。画面の 再ログインする から iSPEED を開き、ログイン → 日経テレコンへ入り直してください。
Drive から「このiPhone内 → Userscripts」が出ない
ファイルアプリで「このiPhone内」（iPad なら「このiPad内」）を表示オンにする。自作フォルダへ保存し、Userscripts アプリでその場所を指定する。

やること / やらないこと

  • 記事ID・タイトル・URLなどの一時記録（端末内、目安24時間）
  • 許諾クリック・検索・見出しオープンの補助（設定でオフ可）
  • ログイン代行、ID/パスワード、Cookie、SSO、有料本文の取得・保管はしません
  • T-Kong 独自サーバーへの送信はしません

ご注意

日経・楽天証券の公式ではありません。すでに楽天証券版日経テレコンを正規利用できる方向けです。対象サイトとの通常のHTTPS通信は発生します。利用は自己責任で、各サービスの規約を守ってください。
